소리 정상파 자동 측정 실험

마이크를 관 안에서 움직이며 소리의 세기를 자동으로 측정하고, 정상파 모양과 파장을 알아봅니다.

1. 실험 설정

실 장력 조절 정지
장력 조절: 새 실험에서 데이터가 비어 있을 때만 사용할 수 있습니다. 정방향은 실제 측정 이동 방향이며, 버튼을 누르면 저속으로 계속 회전하고 정지를 누르면 즉시 멈추고 코일을 해제합니다. JOG로 위치를 움직인 뒤에는 반드시 마이크의 시작 위치를 맞추고 시작 위치 확인을 다시 누르십시오.
첫 데이터 위치: 기본값인 시작 위치 (0 cm)를 선택하면 1회차를 현재 시작 위치에서 먼저 측정하고, 2회차부터 한 번씩 이동합니다. 1회 이동 후를 선택하면 기존 방식처럼 이동한 뒤 1회차를 측정합니다.
실-도르래 구동에서는 미끄럼과 실의 신장 때문에 위치가 절대좌표가 아닐 수 있습니다. 보정값을 입력하면 모든 x축을 추정 위치(cm)로 표시하며, 보정값이 0이면 회차로 표시합니다.
배선: D8~D11 → ULN2003. GND를 UNO Q와 공통으로 연결합니다. A0에는 0~3.3 V 범위만 입력하십시오. 현재 빠른 측정 설정은 모터 20 RPM, 안정화 0.5초, 200 ms × 10회 측정입니다.

새 실험 준비: 필요한 결과를 먼저 저장한 뒤 측정 데이터를 초기화하십시오. 필요하면 위의 장력 조절 JOG로 실을 팽팽하게 만든 뒤 마이크를 시작 표시선에 맞추고 시작 위치 확인을 누르십시오. 이 버튼은 모터를 움직이지 않습니다.
중간 정지 주의: 한 회차의 이동/안정화/측정 도중 정지하면 마이크가 이미 일부 이동했을 수 있으므로 회차-위치 대응을 자동으로 무효 처리합니다. 그 경우 이어서 측정하지 말고 새 실험 준비 절차를 거치십시오.
